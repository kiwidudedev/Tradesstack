## Root cause

The repository did not declare the wrong Next version. `package.json` and
`package-lock.json` both resolved Next `16.3.3`, while the existing Master
`node_modules/next/package.json` was stale at `16.1.6`. `npm ls next` reported
that installation as invalid against the root declaration.

Node was already `22.22.2`. The repository contract required npm `11.6.2`
through `engines` and `packageManager`; the machine's system npm was `10.9.7`.
The correction uses Corepack's repository-declared npm version rather than
changing global npm.
